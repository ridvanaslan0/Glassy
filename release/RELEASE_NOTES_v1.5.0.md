## Glassy v1.5.0

First public release: a tiny round screen magnifier for Windows with a liquid glass edge.

**Highlights**
- `Ctrl+Alt+Z` toggles a round lens that follows your cursor
- Mouse wheel to zoom, Shift + wheel to resize the lens
- Liquid glass edge with refraction, chromatic aberration and a specular rim
- ON/OFF notification, tray menu, settings window, start with Windows
- Visible in screenshots and Discord streams (can be hidden in settings)

**Install:** download the zip, extract it and run `Glassy.exe`.
Windows 10 or 11, 64-bit. SmartScreen may warn because the executable is not code-signed.

See the [README](../README.md) for usage and known limitations.
